# Placement + Semester Command Center

A zero-backend personal dashboard for DSA placement preparation and 5th-semester tracking.

## Deploy
### Vercel
1. Put `index.html` in a GitHub repository.
2. Import the repository into Vercel.
3. Deploy with no build command required.

### Netlify
Drag the project folder into Netlify Drop, or connect the GitHub repository.

## Important
The dashboard stores data in browser localStorage. It persists on the same browser/device.
Use **Export backup** regularly. Cross-device cloud sync can be added later with Supabase/Firebase.
